# 🏃‍♂️ TinyRunner

**TinyRunner** — это минималистичный браузерный раннер с переключением линий, монетизацией и поддержкой Яндекс SDK.

Игрок управляет кубиком, который автоматически бежит вперёд. По клику мыши (или тапу) кубик перепрыгивает на другую линию, позволяя уклоняться от шипов и собирать монеты. Скорость игры постепенно увеличивается, а уровень сложности растёт.

## 🎮 Геймплей

- Бесконечный раннер с прогрессией скорости
- Две линии: верхняя и нижняя
- Переключение линий по клику/тапу
- Препятствия: обычные шипы (смертельны) и призрачные шипы (исчезают при касании)
- Бонусы: джамппады (прыжок вверх), монеты (валюта)
- Магазин скинов с геометрическими стилями
- Рекламные интеграции: вознаграждение за продолжение после смерти

## 🕹️ Управление

- **Тап / ЛКМ** — переключение между верхней и нижней линией
- **Тап во время прыжка** — досрочное прерывание прыжка
- **Кнопка паузы** — остановка игры
- **Магазин** — покупка и смена скинов

## 🛠️ Технологии

| Технология | Применение |
|-----------|-----------|
| Unity 6.3 | Игровой движок |
| C# | Логика игры |
| PluginYG2 | Интеграция с Яндекс.Играми (SDK, реклама, сохранения, локализация) |
| PrimeTween | Анимации переключения линий и эффектов |
| DOTween | Дополнительные анимации (пульсация, шкалы) |
| TextMeshPro | UI тексты с поддержкой локализации |
| WebGL | Платформа сборки |

## 🌍 Локализация

- Поддерживаются **русский** и **английский** языки.
- Язык автоматически определяется по настройкам браузера / платформы.
- Все тексты (счёт, кнопки, рекорды) переведены через модуль Localization плагина PluginYG2.

## 💰 Монетизация

- **Внутриигровой магазин:** скины за монеты
- **Реклама:** межстраничная (после нескольких смертей) и вознаграждение (продолжение игры)
- **Сохранения:** прогресс хранится в облаке через Яндекс SDK

## 🔧 Особенности реализации

- **Object Pool** для переиспользования чанков уровня (оптимизация памяти)
- **Сервисная архитектура** (SpeedService, ScoreService, CoinService, ShopService, LevelService)
- **Централизованное управление состояниями** через GameManager
- **Асинхронная загрузка сохранений** через корутины
- **Событийная модель** для рекламы и смены языка
